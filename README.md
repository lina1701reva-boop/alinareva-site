# alina reva — персональный сайт

Простой статический сайт-визитка (тёмная тема) со ссылками на музыку и соцсети.
Никаких сборок и зависимостей — только `index.html` + `styles.css`.

## Как редактировать

- **Ссылки:** открой `index.html`, найди `href="#"` и вставь свои адреса
  (Spotify, Apple Music, YouTube, Instagram, TikTok, Telegram).
- **Фото:** положи файл `avatar.jpg` рядом с `index.html`, в блоке `.avatar`
  раскомментируй строку `<img ...>` и удали `<span>AR</span>`.
- **Имя/подпись:** правь `<h1 class="name">` и `<p class="tagline">`.

Чтобы посмотреть локально — просто открой `index.html` в браузере
(двойной клик).

## Публикация на GitHub Pages (бесплатно, с HTTPS)

1. Создай на GitHub пустой репозиторий (например `alinareva-site`).
2. Залей в него эти файлы (команды даст ассистент).
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy
   from a branch → Branch: `main` / `root` → Save.**
4. Через минуту сайт будет доступен по адресу
   `https://<логин>.github.io/alinareva-site/`.

## Привязка своего домена (alinareva.xxx)

1. Положи в репозиторий файл `CNAME` с одной строкой — твоим доменом,
   например: `alinareva.com` (файл-заготовка уже есть, впиши точный домен).
2. В настройках домена (у регистратора) добавь DNS-записи:
   - Для **корневого** домена `alinareva.com` — четыре `A`-записи на IP GitHub:
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - Для `www.alinareva.com` — запись `CNAME` на `<логин>.github.io`
3. В **Settings → Pages → Custom domain** впиши свой домен и включи
   **Enforce HTTPS**.

Готово — сайт откроется по твоему домену.
